# VTuber OBS セットアップガイド

## 構成

```
[別PC: 送信側]                    [このPC: 受信・配信側 192.168.0.111]
  キャプボ映像                          OBS
    ↓                               ├── SRTソース (別PCの映像)
  OBS (送信)  →─ SRT over LAN ──→  ├── ブラウザソース (VTuberアバター)
    ↓                               └── 音声ミックス
  映像+音声                                  ↓
                                      YouTube Live RTMP
```

---

## 別PC（送信側）の設定

### 1. OBSをインストール（未インストールの場合）
- https://obsproject.com/ からダウンロード

### 2. キャプチャカードをOBSに追加
- ソース追加 → 映像キャプチャデバイス → キャプボを選択

### 3. SRT送信設定
OBS → 設定 → 配信

| 項目 | 設定値 |
|------|-------|
| サービス | カスタム |
| サーバー | `srt://192.168.0.111:4200` |
| ストリームキー | （空白） |

- 配信開始 → これでこのPC側に映像が届く

---

## このPC（受信・配信側）の設定

### 1. OBSのシーン構成

**シーン: VTuber配信**

| レイヤー（上から） | ソース種別 | 設定 |
|------------------|-----------|------|
| VTuberアバター | ブラウザ | URL: `http://127.0.0.1:7862/stage.html`、1920×1080、ブラウザ音声ON |
| キャプボ映像 | メディアソース | `srt://0.0.0.0:4200?mode=listener`、ループ:OFF |

### 2. メディアソース（SRT受信）設定
- ソース追加 → メディアソース
- 「ローカルファイルを使用する」のチェックを**外す**
- 入力欄: `srt://0.0.0.0:4200?mode=listener`
- 入力フォーマット: `mpegts`（空白でも可）

### 3. ブラウザソース設定
- URL: `http://127.0.0.1:7862/stage.html`
- 幅: 1920 / 高さ: 1080
- 「ブラウザからの音声をキャプチャ」にチェック
- FPS: 30

### 4. 音声ミックス
- SRTメディアソースの音声: ミュート or 小さめ（別PCの環境音）
- ブラウザソースの音声: VTuber TTS音声

### 5. YouTube Live配信設定
- 設定 → 配信 → YouTube - RTMP
- ストリームキーを入力
- 出力設定: 1920×1080 / 60fps / ビットレート 6000kbps

## VTuberシステム起動順序

```
1. start_vtuber.bat を起動（このPC）
   → Rinon Voice Lab + STTパイプラインが立ち上がる

2. 別PCのOBSで「配信開始」（SRT送信）

3. このPCのOBSでシーンを確認
   → メディアソースに別PCの映像が表示される

4. OBSで「配信開始」→ YouTube Live
```

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| SRT映像が映らない | 別PCがSRT送信中か確認 / Windowsファイアウォールでポート4200(UDP)を開放 |
| VTuberの音が出ない | OBSでブラウザソースの音声キャプチャがONか確認 |
| 字幕が出ない | stt_live.pyが起動しているか確認 |
| レイテンシが大きい | SRTバッファ設定: `srt://...?latency=200` に変更 |

---

## ファイアウォール設定（別PCから映像が届かない場合）

このPCで以下を実行（管理者PowerShell）:
```powershell
New-NetFirewallRule -DisplayName "OBS SRT Input" -Direction Inbound -Protocol UDP -LocalPort 4200 -Action Allow
```
